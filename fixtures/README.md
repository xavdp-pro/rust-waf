# Fixtures

Only fictional cases or verifiably anonymized data, with provenance and independently assigned labels. No real orders, accounts, cookies, logs, or database copies.

Label independently of engine outcomes. Separate friend-IP exceptions and scorer fixtures from real protection evaluation. `common-development.json` contains 30 fictional cases with semantic rationale. They were authored by the implementation agent and test initial rules through the real Unix proxy with a recording backend. They are not the independently labeled acceptance corpus. The latter remains pending and cannot be replaced by repeating these examples.
